# Autonomous Mobile Robot Simulation

A PyBullet-based mobile robot simulation for autonomous navigation and task execution, developed as part of my master's studies in Mechatronic Engineering.

## Objectives
- Develop a simulated mobile robot environment.
- Explore autonomous navigation and path planning.
- Investigate mapping and localization techniques.

## Technologies
- Python
- PyBullet

## Current Status
Work in progress. The simulation and autonomous navigation capabilities are being developed incrementally.

## Planned Work
- Implement and test navigation algorithms.
- Explore SLAM (Simultaneous Localization and Mapping).
- Evaluate the robot's performance in simulation.
